# Foundations of String Theory

This repository contains Xi Yin's string notes, their LaTeX source, and
companion Mathematica code for selected calculations.

- [`string notes.pdf`](string%20notes.pdf): current compiled PDF
- [`texsource/`](texsource/): TeX source, bibliography, style file, and figures
- [`codes/`](codes/): Mathematica notebooks and helper packages

Comments, corrections, and feedback may be sent to `xiyin@fas.harvard.edu`.

## Code

The [`codes/`](codes/) directory contains Mathematica notebooks checking or
demonstrating conventions and calculations used in the notes. See
[`codes/README.md`](codes/README.md) for a file-by-file list.
